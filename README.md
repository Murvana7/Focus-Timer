# ⏱️ Focus Timer

A minimal **Focus Timer** designed to help you stay productive by managing focused work sessions and breaks.  
Clean UI, simple controls, and distraction-free design.

## ✨ Features

- Start / pause / reset timer
- Custom focus duration
- Optional break sessions
- Visual countdown indicator
- Minimal, responsive interface
- No sign-up, no distractions
